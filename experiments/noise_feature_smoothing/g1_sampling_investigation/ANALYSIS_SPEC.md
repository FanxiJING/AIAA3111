# G1 and joint sampling-speed diagnosis

Created before computing this round's new tables. This is an exploratory,
post-hoc analysis of existing test artifacts, after prior test results were
already inspected. It is not a preregistration or new independent experiment.

## Fixed inputs and scope

Reuse the original G1/G2/G3 models, 16 iid feature caches, stored raw scores and
predictions, and followup_rounds nearest-landmark diagnostics. Do not train,
tune, perturb coordinates, regenerate features, alter smoothing, resample
users, drop points, or change the frozen protocol. G4 remains skipped.
Store everything in this new directory. Protect prior files with SHA-256 and
membership checks; exclude only this directory, generated bytecode/cache files,
and the explicitly editable AIGC disclosure log.

## Questions and units

1. Does G1 retain substantial landmark response while moving between decision
   regions? Describe nearest-landmark identities, their frozen-model responses,
   prediction agreement, score gaps and feature shifts. A landmark's response
   is the model's prediction at that standardized feature vector, NOT its
   training ground-truth label. No training provenance will be invented.
2. How does noise damage vary jointly with clean sampling interval and mean
   speed? Reuse the previous dt bins: <=1s, (1,2]s, (2,5]s, >5s, invalid
   (nonfinite or nonpositive). Clean mean-speed bins: [0,0.5], (0.5,2], >2 m/s,
   invalid (nonfinite or negative). The numeric 0.5/2 thresholds are borrowed
   from inherited point STOP/SLOW thresholds, but window mean-speed bins do
   not identify true stationary/slow travel states.
3. Retain all 20 Cartesian cells, including empty cells. Report support by
   actual point class and linked user group to reveal composition. Quantities
   are descriptive; do not interpret cross-cell differences as causal effects.

For questions 1-2, use sigma=0 once, sigma=5/10/20 with all five fixed seeds.
Use 17,380 original windows, their actual per-class counts (860,972 points),
13 test users and nine linked groups. Do not replace mixed-window class counts
with majority labels. Class-conditioned feature summaries use window-majority
labels and will be explicitly marked as window summaries.

## Measures

- Each joint cell: fixed-five-class point Macro-F1, Accuracy, per-class TP and
  support, predicted class totals, clean-correct points, noisy-correct points,
  damaged (clean-correct -> noisy-wrong), rescued (clean-wrong -> noisy-correct),
  prediction-changed points. Report conditional damage/clean-correct and
  rescue/clean-wrong with denominators; zero denominators give missing values.
- Full linked-group x joint-cell tables accompany pooled tables. No new
  confidence intervals: five seeds measure artificial noise variability only.
  Report seed means and sample SD separately; sigma=0 has n=1 and SD missing.
- G1: landmark-response class transition tables, point-weighted actual model
  prediction transitions, kernel summaries, model/nearest-response agreement,
  nearest-identity and nearest-response changes. Retain all class pairs,
  including zero counts. Score gap is top score minus runner-up, not a
  calibrated confidence, and its size is not compared between models.
- G1 max-kernel diagnostic bins: [0,0.1), [0.1,0.5), [0.5,0.9), [0.9,1].
  These post-hoc descriptive bins are not a validated OOD detector.
- G1 signed and absolute feature changes in frozen training-scale units:
  window medians for all windows and each clean majority class. No additive
  claim about F1 loss; no causal feature attribution.
- No new figures; tables and a Chinese findings draft suffice.

## Verification and delivery

1. Metadata, timestamps, original point counts, dt and cell membership invariant
   over all 16 caches and aligned with all 48 predictions.
2. Every joint partition and every group partition conserves counts; global
   confusion/F1 matches existing followup summaries.
3. Damage minus rescue equals loss of correctly predicted points, including
   mixed windows. Sigma=0 has no changes.
4. Independently verify full joint-cell confusion and flow counts using a
   separate implementation, including sklearn weighted metrics for all cells.
   Check a deterministic 32-window sample per model-condition against actual
   Pipelines and direct RBF distances. Verify G1 landmark responses using
   inverse-transform + the full Pipeline.
5. Input/protected inventory before and after, code hashes, runtime versions,
   checkpoint, source-reading limits and independent acceptance record.
6. Update docs/aigc_log_part2.md; Chinese prose remains a draft for student
   verification and rewriting. Do not claim new independent-user evidence,
   calibration, real GPS-error validation, or a confirmed general model ranking.

contains missing feature values. The diagnostic summary implementation was
corrected to take medians of finite observed values and explicitly export
finite-value counts. Model-space shifts still use the frozen imputer on ALL
windows. No point/window, model input, existing result or bin was changed.
The entire diagnostic and independent verification are rerun after this fix.
