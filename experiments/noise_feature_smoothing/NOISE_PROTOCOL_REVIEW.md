# GeoLife 噪声实验方案复核

核查日期：2026-11-23。用途：团队内部实验设计与核查记录，不是可直接提交的课程报告。

## 结论与边界

方案可以实施，适合回答：固定 Part 2 v2 分类器，对原有质控后测试轨迹额外增加定位误差，分类性能如何变化？

这不等于已经完成噪声实验，也不能证明整个原始 GPS 清洗流程的鲁棒性。当前没有重新训练 v2 模型，没有生成各噪声档位的分类结果。

课程 `03. Project-3 (2).pdf` 共三页，第 1 页明确将 noisy/incomplete data 列为可研究条件。课程没有规定高斯噪声、噪声档位或随机种子数量，也没有承诺某种方案对应高分。报告还须遵守课程的 AIGC 披露要求。

## 逐项核查

| 核查项 | 结果与实施约束 |
|---|---|
| 参考版本 | 使用 `AIAA3111-part2-fixes/docs/part2_handover.md` 的 v2，不能混用旧根目录 README 的设置 |
| 参考配置 | 50 点窗口，27 特征，不含 `dt_mean/dt_max`；Nystroem RBF + LinearSVC，C=1、balanced；soft 平滑 k=11 |
| 模型持久化 | v2 的 `stage_final` 丢弃拟合模型，没有保存 v2 estimator；现有旧目录的 `best_model.joblib` 不能直接充当 v2 |
| 数据条件 | 已有 quality_features Parquet 和原始窗口表，足以做“质控后额外坐标扰动” |
| 坐标噪声 | 东向、北向分别为零均值、标准差 sigma 米的高斯；使用米制位移映射到经纬度，不能直接向角度加米数 |
| sigma 的含义 | 每轴 sigma，不是径向 RMS；径向 RMS 为 sqrt(2)*sigma，高斯误差也没有 sigma 米的最大值边界 |
| 零噪声 | sigma=0 指不增加误差，原始观测本身仍可能有误差；零档位直接保留原坐标 |
| 特征重算 | 在完整 feature block 上重新计算运动量，再汇总窗口；不能只改 Parquet 坐标而沿用旧速度、加速度等 |
| 固定比较对象 | 保留点、时间、标签、原 block、盲切 50 点窗口及各窗类别计数 |
| 质控范围 | 主实验不在加噪后重跑基于速度的连接修复，否则 block 与窗口会改变，研究问题也改变 |
| 训练流程 | 原训练集只拟合一次；imputer、scaler、Nystroem 和分类器都冻结，不在测试数据上重新 fit |
| 特征列 | 保存并严格使用训练时的 27 列及顺序；噪声强度、种子、诊断数字单独存表，不能被自动选作模型输入 |
| 平滑 | 同时报告 raw 与固定 k=11 soft 结果；不依据测试表现调 k。当前居中平滑是离线处理 |
| 评估单位 | 主指标从每窗真实类别点数构造点级混淆矩阵，不把窗口多数标签准确率当作点级成绩 |
| F1 口径 | `metrics_from_cm` 平均固定五类，`_macro_f1_accuracy` 只平均真实存在类别；两者是不同定义，缺类时不能静默混用 |
| 不确定性 | 以 9 个重复关联用户组做配对 bootstrap，同一次抽样用于全部条件；随机种子波动与跨用户组不确定性分开报告 |
| 结果解释 | 不能预先保证分数单调下降或去噪一定有效，也不能挑掉不符合预期的随机种子 |

## 实际运行的核查

脚本：`tmp/check_noise_protocol.py`，在整合仓库下用 `.venv-audit/Scripts/python.exe` 运行，退出码 0。未修改原始数据、已有研究代码或结果。

- 全部 13 个测试用户，860,972 个点，17,380 个窗口。
- 零噪声重建：全部 27 个特征与保存表一致，最大绝对差为 0；窗口元数据、每类点数等也一致。
- sigma=20 米、一个预设种子：时间间隔、窗口身份、标签与类别计数不变；17,363 个窗口的特征发生变化。
- 此次扰动结果中有 1,118 个速度超过 100 m/s 的间隔。这是需要记录的扰动效应，主实验不能因此临时删点或重切窗口。
- 测试集为 9 个关联用户组；最大组占测试点数 78.8832%，需同时展示逐用户表现。
- 构造的单类别全对混淆矩阵：固定五类 F1=0.2，真实存在类别 F1=1.0，确认口径差异。
- sigma=5 米的独立高斯模拟：径向 RMS=7.0692 米，符合 sqrt(2)*5；静止轨迹平均相邻位移=8.8720 米，接近理论值 sqrt(pi)*5=8.8623 米。

这只是数据与特征可实施性核查，不是所有档位、种子、模型预测的完整端到端测试。特征计算复用了原实现，检验的是与参考流程的一致性，不是对所有特征公式的独立数学验证。

## 文献证据的准确范围

1. Endo 等，*Deep Feature Extraction from Trajectories for Transportation Mode Estimation*，PAKDD 2016，作者预印本第 9 页 §5.4、第 10 页 Figure 4(a)。直接核实了“向已有观测轨迹追加零均值高斯噪声，比较不同强度分类表现”的实验做法。但这项噪声实验使用 KT 数据集，不是 GeoLife，不能写成 GeoLife 上已验证本方案。原文第 10 页横轴显示 sigma 约 2–30 米；本项目的 0/5/10/20 米是自行预设的实验档位，不是假称完全复现该论文。
2. Zeng 等，*Addressing robust travel mode identification with individual trip-chain trajectory noise reduction*，DOI `10.1049/itr2.12243`。通过 Crossref 读取出版方提供的摘要，确认定位噪声影响运动特征、比较多种去噪方法及噪声情景的研究动机。出版方全文访问受限，因此此前关于其确切 sigma 档位和固定噪声方向的说法不作为已核实依据，应撤回；摘要也不能证明其结论必然适用于当前 SVM。
3. Microsoft GeoLife 用户指南页面的 1–5 秒、5–10 米描述采样间隔，不是定位精度，不能据此声称本项目噪声参数已由 GeoLife 真实误差校准。
4. 对 *Why GPS makes distances bigger than they are* 仅核实了题名和 DOI `10.1080/13658816.2015.1086924`；本次未取得全文，不将其关于相关噪声的具体公式作为已经逐项核实的依据。

## 建议锁定的最小主实验

1. 原训练数据拟合并保存一次精确 v2 流程，先复现零附加噪声预测；参考保存结果 raw Macro-F1=0.7789、soft k=11 为 0.8443，尚未由本次重新训练验证。
2. 预设 sigma=0/5/10/20 米、5 个固定随机种子。不同强度复用同一标准正态场乘以 sigma；这是降低比较随机波动的设计选择，不是“5 次足以保证统计可靠”的定理。
3. 每个条件从原测试坐标产生扰动，重算 block 内运动特征与原窗口特征，用同一个冻结模型预测。
4. 主表报告 raw/soft 的固定五类点级 Macro-F1、Accuracy、逐类 F1；另报逐用户表现及定义。
5. 画强度与分数的关系，区分种子均值/标准差和基于用户组的配对变化区间；展示一个速度膨胀或分类失败案例。
6. 时间相关噪声、坐标去噪、训练增强均可作为后续独立扩展；不混入这项固定模型的主实验，也不把独立高斯当作所有真实 GPS 误差的完整模型。
